# Attendance-Based Hall Ticket Generation System

Backend and frontend scaffold for a production-ready MERN attendance and hall ticket system.

## Structure

- `backend/`: Express.js API with JWT authentication, Mongoose models, file uploads, PDF generation, and role-based routes.
- `frontend/`: React app with protected routes, dashboards for HOD, Faculty, Mentor, and Student.

## Backend models created

- `User`
- `FacultyAllocation`
- `Student`
- `Attendance`
- `Document`
- `HallTicket`
